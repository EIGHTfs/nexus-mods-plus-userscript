# 发布到 ScriptCat 说明

## 一、能不能发布

| 项目 | 结论 | 依据 |
|---|---|---|
| 法律 | 可以 | 原脚本 `@license MIT`，MIT 明确允许修改与再分发，条件是保留版权与许可声明 |
| 平台 | 可以 | ScriptCat 免责协议第 3 条：不对用户上传的脚本做内容审查，责任由上传者承担 |
| 署名 | 已保留 | `@author SmallRob, EIGHTfs`，头部注释注明基于原脚本修改 |

原脚本：https://scriptcat.org/zh-CN/script-show-page/8917

> 说明：ScriptCat 免责协议第 4 条「不得复制、修改、再发布」针对的是 **ScriptCat 平台自身**的代码与文档，不是用户上传的脚本，不要误读。真正的约束来自脚本自己的许可证（MIT）。

## 二、元信息已改成可发布状态

| 字段 | 值 | 为什么要改 |
|---|---|---|
| `@namespace` | `nexusmods-enhancer-e8` | 原值 `nexusmods-enhancer` 与原作者相同。ScriptCat 按 namespace + name 识别脚本，相同会被当成同一脚本的更新，可能互相覆盖 |
| `@name` | `Nexus Mods 增强（下载增强版）` | 避免与原版同名造成安装混淆 |
| `@author` | `SmallRob, EIGHTfs` | MIT 要求保留原作者署名，同时署上维护者 |
| 头部注释 | 基于原脚本修改 + 原地址 + 主要改动 | MIT 的署名与来源追溯要求 |

元数据块放在 `// ==UserScript==` 与 `// ==/UserScript==` 之间，版权声明放在块**之后**——放进块内会被当成 `@` 字段解析，破坏元数据。

## 三、发布步骤

1. 打开 https://scriptcat.org/ 登录
2. 顶部「发布脚本」→「新建脚本」
3. 把 `nexus-mods-plus.user.js` 全文粘贴进去
4. 填写发布信息：
   - 脚本名：`Nexus Mods 增强（下载增强版）`
   - 简介：取头部 `@description`
   - 分类：站点增强 / 下载工具
   - 标签：`NexusMods`、`下载`、`中文`、`断点续传`
5. 提交发布

## 四、版本更新

ScriptCat **保留历史版本**（实测：原脚本有 1.3.1 / 1.3.2 / 1.3.3 三条记录，各自独立 id），所以发布后可以继续迭代，旧版可回退。

更新方式：修改 `@version` → 重新发布 → 平台记录为新版本。

## 五、安装注意事项

改过 `@namespace` 后，本脚本在平台上是**另一个脚本**，与原版 1.3.3 并存。

安装前请先在脚本管理器里**删除原版 Nexus Mods 增强 1.3.3**，否则两个脚本会同时注入页面，功能重复触发（下载按钮会出现两次、面板叠加）。

## 六、上传者需要承担的事

原脚本在 ScriptCat 上 `user_id = 0`（未绑定账号），基本处于不维护状态。发布增强版后：

- N 网改版导致 DOM / 接口变化，需要及时跟进
- 用户反馈与问题排查由维护者负责
- 版本迭代时保持 `@version` 递增

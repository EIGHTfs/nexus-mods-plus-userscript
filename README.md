# Nexus Mods 增强

给 Nexus Mods 网页加中文界面、筛选排序、AI 翻译与按 mod 归档下载的油猴脚本。

## 功能

| 功能 | 做什么 | 入口 |
|---|---|---|
| 按 mod 归档下载 | 自动建 `<游戏名>/<Mod名>/`，安装包写进去 | 下载面板 |
| 断点续传 | 下载中断、切后台、刷新页面后从断点继续，不从头重下 | 自动 |
| 脚本设置面板 | 集中管理下载 / 界面 / AI 三类设置 | 浮坞「⚙ 配置」或脚本菜单 |
| 图片独立下载 | 单独下当前 mod 的预览图原图 | 下载面板「下载图片」 |
| 合集批量下载 | 每个 mod 各自一个文件夹，支持暂停续传 | 合集页下载面板 |
| 下载历史 | 标出有更新版本的已下载模组 | 下载面板 |
| 界面中文化 | 列表与详情页中文文案、模组语言徽章 | 自动 |
| 筛选 | 语言、下载量、点赞数、文件体积 | 列表页工具条 |
| 排序 | 9 种：发布/更新/下载/独立下载/点赞/名称/体积/评论/随机 | 列表页工具条 |
| 每页条数与无限滚动 | 20/40/60/80 条可选，滚到底自动加载 | 列表页工具条 |
| 中文游戏名直达 | 输入中文游戏名跳到对应游戏页 | 浮坞 |
| AI 翻译与分析 | 详情页 AI 翻译、结构化分析 | 详情页 AI 区 |
| 跳过下载等待页 | 自动跳过下载倒计时 | 自动 |

## 环境要求

| 浏览器 | 脚本管理器 | 归档通道 |
|---|---|---|
| Chrome / Edge | ScriptCat、Tampermonkey、Violentmonkey | 文件系统通道（可自选目录）或 GM_download |
| Firefox | Tampermonkey | 仅 GM_download |

## 用法

### 安装

1. 下载仓库里的 `nexus-mods-plus.user.js`
2. 在脚本管理器（ScriptCat / Tampermonkey / Violentmonkey）里新建脚本，粘贴内容并保存

仓库为私有，raw 链接需要 token 才能访问，因此不走一键安装。

### 第一次使用

1. 打开任意 mod 详情页，右下角浮坞点「⬇ 下载」
2. 点「① 选择保存目录（建文件夹必选）」，选一个根目录（可选网络盘）
3. 之后每次下载自动在该目录下建 `<Mod名>/`

目录授权只需一次；浏览器重启后若提示过期，再点一次按钮即可。

### 下载面板

```
按 mod 建文件夹        勾选：下载时自动建 <Mod名>/ 目录
下载时附带图片         勾选：安装包与预览图一起下；默认不勾
下载图片               只下当前 mod 的预览图原图，不碰安装包
① 选择保存目录         选根目录；不选则退回浏览器下载目录
```

### 脚本菜单

```
归档下载：自测能否自动建文件夹        往 NME自测/ 写一张测试图，验证通道
下载历史：重新检查更新                重新比对已下载模组的版本
下载等待页自动跳过：开 / 关            切换跳过下载倒计时
```

### 产物结构

```
<保存目录>/
└── <游戏名>/
    └── <Mod 标题>/
        ├── <原始文件名>.zip
        ├── 868-1760599327-512078410.png
        └── 868-1760599338-1231626948.png
```
